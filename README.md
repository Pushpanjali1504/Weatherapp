# 🌦️ WeatherApp – Smart Weather Forecasting & Air Quality Monitoring System

**WeatherApp** is an interactive and user-friendly weather forecasting web application that provides real-time weather updates, five-day forecasts, hourly temperature visualization, and air quality information for different locations.

Built using HTML, CSS, and JavaScript, this project combines live weather APIs with an attractive dashboard to make weather monitoring simple and informative.

---

## ✨ Key Features

- 🔐 **Login Page:** Simple demo login with fixed username and password.
- 🔍 **City Search:** Search weather conditions for different cities.
- 📍 **Current Location:** Get weather updates based on your current location.
- 🌡️ **Live Weather Information:** Check current temperature and weather conditions.
- 📅 **5-Day Weather Forecast:** View upcoming weather predictions.
- ⏰ **Hourly Forecast:** Explore hourly temperature changes.
- 🌫️ **Air Quality Monitoring:** Check air quality information.
- 🗺️ **Interactive Weather Map:** Explore locations through an interactive map.
- 🌙 **Dark/Light Mode:** Switch between dashboard themes.
- 🚪 **Logout Option:** Exit the dashboard.

## 🚀 How to Run Locally

**1. Clone the repository**

```bash
git clone https://github.com/YOUR-USERNAME/WeatherApp.git
```

**2. Open the project folder**

```bash
cd WeatherApp
```

**3. Run the application**

- Open the folder in Visual Studio Code.
- Install the Live Server extension.
- Right-click on `index.html`.
- Select **Open with Live Server**.

Your WeatherApp will open in your browser.

## 🌐 APIs and Services

WeatherApp uses the following services:

- [Open-Meteo Weather API](https://open-meteo.com/)
