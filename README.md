# 🌦️ WeatherWise – Smart Weather Forecasting & Air Quality Monitoring System

**WeatherWise** is a smart, interactive weather monitoring web application designed to provide real-time weather information, upcoming forecasts, and air quality updates for different locations.

The project combines weather data visualization with a modern dashboard to help users understand current atmospheric conditions and plan their daily activities.

---

## 🌍 Project Overview

WeatherWise is developed using HTML, CSS, and JavaScript. It fetches live weather information from weather APIs and displays it through an attractive and user-friendly interface.

Users can search for different cities, view current weather conditions, explore upcoming forecasts, and monitor air quality.

## ✨ Features

- 🔐 **Login System:** Simple demo login to access the dashboard.
- 🔍 **City Search:** Search for weather information by city name.
- 📍 **Current Location:** Get weather information based on your device location.
- 🌡️ **Live Weather Updates:** View current temperature and weather conditions.
- 📅 **5-Day Forecast:** Check upcoming weather conditions.
- ⏰ **Hourly Forecast:** View temperature variations through an interactive chart.
- 🌫️ **Air Quality Monitoring:** Display air quality information.
- 🗺️ **Interactive Map:** Explore locations using an interactive map.
- 🌙 **Dark/Light Mode:** Switch between different dashboard themes.
- 🚪 **Logout:** Exit the dashboard securely from the demo interface.

## 🚀 How to Run the Project

Follow these steps to run WeatherWise on your computer.

**Step 1: Clone the repository**

```bash
git clone https://github.com/YOUR-USERNAME/WeatherWise.git
```

**Step 2: Open the project folder**

```bash
cd WeatherWise
```

**Step 3: Open the project**

- Open the folder in Visual Studio Code.
- Install the Live Server extension if needed.
- Right-click `index.html`.
- Select **Open with Live Server**.

The application will open in your browser.

## 🌐 APIs and Data Sources

WeatherWise uses the following services to retrieve information:

- **Open-Meteo:** Weather forecast and current weather data.
- **Open-Meteo Geocoding:** City search and geographical coordinates.
- **Open-Meteo Air Quality:** Air quality and atmospheric data.
- **OpenStreetMap:** Interactive map data.

These services allow the application to display updated information through internet connectivity.
